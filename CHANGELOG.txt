JULIUS WORKROOM v1.3.1
======================

- 既存Julius台詞を維持したまま、指定された新規台詞を状況別カテゴリへ追加
- 同一カテゴリの直近3件（候補が少ないカテゴリは直近1件）をセッション内で除外
- 小さな一歩、WORK完了保存、EXERCISE新規記録へ短い合成UI SEを追加
- 軽いUI SEのON/OFFとQUIET/NORMAL音量を設定へ追加
- UI SE設定を端末専用 `julius_workroom_device_ui_v1` へ保存し、Cloud SyncとJSONから分離
- 既存タイマー終了SE、localStorageメインキー、schema version 10、JSON、Cloud Sync互換を維持
- Service Workerキャッシュをv1.3.1へ更新

JULIUS WORKROOM v1.3.0
======================

- PC版CALENDARを上段WORK／下段EXERCISEの縦2段表示へ変更し、スマホ版の切り替え表示は維持
- PCナビゲーションを HOME / WORK / EXERCISE / CALENDAR / LOG の順へ変更
- UI確認後の調整として「小さな一歩」6項目をPC／スマホとも一行表示へ変更
- PC版WORKを2列×2段へ再配置（ACTIVE PROJECTS｜WORK TREE / FOCUS TIMER｜TODAY'S BREAKDOWN）
- WORK内の主要文字サイズとカード余白を拡大し、WEEKLY REVIEWを独立した全幅カードへ移動
- PCナビゲーションを HOME / WORK / EXERCISE / CALENDAR / LOG の5項目へ整理
- PROJECTS / TIMER / STATSをWORK画面へ統合
- WORK画面にACTIVE PROJECTS、WORK TREE、FOCUS TIMER、WEEKLY REVIEW、TODAY'S BREAKDOWNを集約
- WORK / EXERCISEの月間カレンダーをCALENDAR画面の切り替え表示へ統合
- スマホWORKではFOCUS TIMERを先頭付近へ配置
- スマホEXERCISEを3列の運動選択、月間3指標、直近5件中心の高密度表示へ変更
- PC／スマホのナビゲーションへローカルSVGアイコンを追加
- 既存localStorageキー、保存スキーマversion 10、JSONバックアップ、Cloud Sync v1.2.1互換を維持
- 新しいUI操作音は追加せず、既存タイマー終了SEを維持
- Service Workerキャッシュをv1.3.0へ更新し、ナビアイコンをApp Shellへ追加

JULIUS WORKROOM v1.2.1
======================

- 前回同期したrevisionと安定ハッシュをUIDごとに端末へ記録
- オブジェクトのキー順に左右されない安定ハッシュへ変更
- ローカルが前回同期時点から未変更で、クラウドだけが新しい場合は安全に自動反映
- ローカルとクラウドの両方に変更がある場合の手動選択と安全バックアップを維持
- 既存localStorage、JSONバックアップ、Firestoreデータ形式との互換性を維持
- Service Workerキャッシュをv1.2.1へ更新

JULIUS WORKROOM v1.2.0
======================

- Googleログイン／ログアウトUIを追加
